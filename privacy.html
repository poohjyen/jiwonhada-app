개인정보처리방침

지원하다 업로드 · 시행일 2026년 11월 15일

「지원하다 업로드」는 유튜브 채널 「지원(支援)하다」 운영자 한 사람이 자기 채널에 영상을 올리는 데 쓰는 개인용 도구입니다. 다른 사람의 계정에는 쓰지 않습니다.

받는 정보

  • 운영자가 구글 계정으로 동의해 받은 유튜브 접근 토큰
  • 연결한 채널의 이름과 ID
  • 이 도구로 올린 영상의 ID, 공개 예약 시각, 처리 상태

쓰는 곳

운영자 PC에서 영상을 비공개로 올리고 공개 시각을 예약하는 일, 썸네일과 재생목록을 넣는 일, 제대로 올라갔는지 다시 확인하는 일에만 씁니다.

보관과 제공

토큰은 운영자 PC에만 윈도우 암호화(DPAPI)로 잠가 저장합니다. 서버로 보내지 않으며, 누구에게도 제공하거나 팔지 않습니다. 광고에도 쓰지 않습니다.

Google API에서 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

권한 끊기

myaccount.google.com/permissions에서 언제든 이 도구의 접근 권한을 끊을 수 있습니다. 끊으면 운영자 PC의 토큰도 더는 쓸 수 없습니다.
